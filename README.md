# RekenSlim.be — AdSense-voorbereide versie

Deze versie bevat een uitgebreidere structuur met afzonderlijke calculatorpagina's, uitleg, voorbeelden, FAQ's, disclaimer, privacy-informatie, robots.txt en sitemap.xml.

## Belangrijk

Dit pakket is **technisch voorbereid op een toekomstige Google AdSense-integratie**, maar dat betekent niet dat Google de site automatisch goedkeurt. Google beoordeelt iedere site afzonderlijk.

## Huidige URL

De pagina's gebruiken voorlopig als canonical URL:
`https://gianni264-m.github.io/RekenSlim/`

Wanneer je later een eigen domein koppelt, moeten de canonical URL's, sitemap en robots.txt worden aangepast naar het nieuwe domein.

## Wat moet je nog zelf doen vóór AdSense

1. Publiceer de bestanden op GitHub Pages.
2. Controleer alle pagina's en calculators op desktop en mobiel.
3. Vervang de tekst op de contactpagina door een echt e-mailadres dat je beheert.
4. Vul de privacyverklaring aan zodra je daadwerkelijk AdSense, Analytics of andere diensten activeert.
5. Als je AdSense gebruikt, volg de actuele Google-instructies voor de verificatiecode, privacy/consent en `ads.txt`. Voeg geen verzonnen publisher-ID toe.
6. Gebruik geen eigen advertentieklikken om inkomsten te testen.

## Uploaden

Upload de bestanden uit deze map naar de root van je GitHub Pages repository `RekenSlim`. Overschrijf de oude `index.html`, `style.css` en `privacy.html` en voeg de nieuwe `.html`-pagina's, `robots.txt` en `sitemap.xml` toe.

## SEO

Iedere calculator heeft een eigen titel, meta description, canonical URL, uitleg en FAQ. De site heeft ook een sitemap en robots.txt.

## Advertenties

Er staan alleen duidelijke placeholders met “Advertentieruimte”. Er is nog geen advertentiecode toegevoegd, omdat die pas zinvol is nadat je AdSense-site is aangemaakt en Google je de benodigde code/instructies geeft.
