# RekenSlim.be — eerste versie

Open `index.html` om de website lokaal te bekijken.

## Inbegrepen
- Responsive homepage
- 8 calculator-kaarten
- Werkende calculators voor BTW, korting, percentages, leeftijd, datumverschil, uurloon/maandloon en kilometervergoeding
- Zoekfilter
- Belgische nl-BE interface
- Basis SEO metadata
- Over ons, privacy en contact pagina
- Advertentieruimte als placeholder

## Publiceren
Je kunt deze statische bestanden hosten bij vrijwel elke webhost of statische hostingdienst. Upload alle bestanden uit deze map.

## Belangrijk vóór monetisatie
- Vervang de voorbeeldtekst/contactgegevens.
- Maak privacy/cookie-informatie passend bij je echte setup.
- Voeg een echte cookie/consent-oplossing toe als dat voor jouw advertentie- of analyticsconfiguratie nodig is.
- Voeg pas advertentiecode toe nadat je advertentieaccount is goedgekeurd.
- Controleer Belgische regelgeving en eventuele officiële tarieven/bedragen voordat je calculators voor formele financiële doeleinden gebruikt.
